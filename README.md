This is a game I created for the Chicago indie game scene's Halloween 2025 game jam showcase. It's effectively launching software for other games that were part of the showcase, acting sort of as it its own little horror game. 
WASD to move forward/back and strafe, Q/E to rotate your view. The stiffness of the controls is intentional, I wanted to replicate the movement in late 80's early 90's dungeon crawlers because I like the way the limitations
makes the environment feel a little more claustrophobic. The spacebar *would* open one of the relevant games, but I don't feel comfortable including other people's work in a public repository. Instead it just makes a fun door creaking sound if you're looking at a door haha.

The hotel is procedurally generated from small set pieces called Sections. The hotel itself gets built and broken down as the player moves from section to section, the idea was to make it really easy to for players to feel like they're lost. Also had the bonus effect of 
the game being able to be set up and left running for the duration of the showcase without the need for restarting.

This project was written over the course of about 4 days so a lot of sacrifices needed to be made with regards to cleanliness, but I think given the time constraint it turned out pretty clean. I'm also not 100% sure if this was the final version I had at the showcase, it was kind of a
hectic couple days leading up to the release so I very well could have made some last minute changes the day of that I never committed.



If you run into any errors around asset imports, you might need to download blender and set it up to be used with Godot. Should be able to find up steps on setting that up online easily enough!
